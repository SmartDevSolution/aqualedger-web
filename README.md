# AquaLedger Web

Private Next.js/TypeScript web repository in the personal AquaLedger family.

Product decisions and status: https://github.com/AmeenBinBisher/aqualedger

This is a one-time documentation-only seed for an empty repository. It is not an implemented application or release. The foundation documentation PR must be independently reviewed and receive final Council scope review before merging to dev and beginning feature implementation.

Scope: two primary screens (Analysis Workspace and Settings/Data Sources), English/LTR and Arabic/RTL from the first UI implementation. API/analysis/worker/Supabase migrations belong in aqualedger-backend, not here. No mobile work.

Normal changes use task branches and PRs to dev. main remains reserved for owner-approved releases. No application run commands or successful tests are claimed by this seed.
